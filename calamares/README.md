# Calamares

Directorio para configuraciones de Calamares y branding Zentrix.

La integracion base se implementa en `archiso/airootfs/etc/calamares/` y
`archiso/airootfs/usr/share/calamares/branding/zentrix/`.

Este directorio `calamares/` se reserva para plantillas, pruebas y archivos
de soporte fuera de la imagen live.
